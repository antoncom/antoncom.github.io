2021–2022 · Phoenix Baseball Systems（美国）

FireBall 投球模拟器：控制系统架构

FireBall 是一款气动投球模拟器，能与投手视频同步再现真实的 MLB 投球。我受托设计其嵌入式控制系统，并开始了实现工作。

客户
Phoenix Baseball Systems（美国）
时间
2021–2022
角色
软件架构师 / 开发工程师，合同
技术栈
C, Lua, ubus, UCI, Ubuntu, NXP i.MX8M; ClearPath-SC servos, NI USB-6001 I/O

任务

六个伺服轴（俯仰、横滚、偏航、Z 轴和两台最高 3,200 rpm 的旋转电机）、13 路数字输出（电磁阀、激光、指示灯、警报）、模拟传感器（倾角、压力、球到位）、同步视频播放、RESTful API 以及基于角色的无线 Web GUI——全部运行在 NXP i.MX8M (Nitrogen8M) 单板计算机上。

提出的架构

下载完整文档 (PDF)

投球场景是 Lua 规则；机器的基本动作是 C 编写的应用层驱动；其下是硬件厂商的 API；所有部分通过系统总线连接。同样的分层结构后来在路由器固件中投入量产。

我做了什么

  • 分析客户需求，并提出了上述分层架构。
  • 将 OpenWrt 的 ubus 和 UCI 移植到 Ubuntu（目标系统为 Ubuntu Core），使控制器能使用与 OpenWrt 设备相同的工具。
  • 用 C 编写了规则引擎的第一部分：数据模型（模块、规则、来源为 UCI / ubus / 常量的变量、带类型的值）、按周期的数值缓存，以及基于 uloop 的求值循环。
  • 用英语进行商务谈判，并起草了带四个附件的合同：分阶段交付 MVP（规划、估算、调研、开发、附源代码演示）、付款计划、共用设备和进度风险。
  • 定义了 MVP-1：集成伺服电机、I/O 设备、继电器和倾角传感器的测试台。

由于硬件套件无法运往俄罗斯，项目于 2022 年初暂停。
