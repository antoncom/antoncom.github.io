2022–2023 · Wimark Systems (Moscow, Skolkovo)

OpenWrt platform migration for 2,000–3,000 managed Wi-Fi access points

Wimark develops Wi-Fi network management solutions — an operator platform and an enterprise WLAN controller. Its access points run OpenWrt-based firmware with a CPE agent written in Lua: the on-device component that connects each access point to the central portal for monitoring and firmware updates. I joined the small firmware team (team lead and two developers) and for 12 months maintained and migrated this firmware.

Client
Wimark Systems (Moscow, Skolkovo)
Period
2022–2023
Role
Firmware developer, remote contract
Stack
C, Lua, hostapd, busybox, ubus, UCI, OpenWrt build system, SNMP

What I did

  • Migrated the firmware across two major releases — OpenWrt 19.07 → 21.02 → 22.03 — porting the company's customizations each time.
  • CPE agent (Lua): analysed and patched it for the new OpenWrt releases, keeping the link between devices and the portal working.
  • Zero-touch provisioning: implemented DHCP option 43 handling in busybox udhcp and fixed the CPE agent so a new access point finds the controller address via option 43; built a dedicated test bench.
  • hostapd (C): ported and extended patches — ubus objects and methods for interfaces, client accounting, channel switching and channel data in state events; enabled 802.11ax (HE) and Hotspot 2.0. Set up remote debugging for the patch work.
  • Ported the company's SNMP daemon to the new releases.
  • Brought up the firmware on new hardware: Yuncore AX880 (Wi-Fi 6), QWP-88; TP-Link TL-MR3020 v3 as the reference device.

How I worked

Tasks came from the team lead through the shared tracker. For every task I ran a short technical investigation first, then turned it into a refined specification — test scenarios and bench descriptions — and only then gave an estimate.

Result

Eleven monthly deliveries over a year, all accepted by the client.
