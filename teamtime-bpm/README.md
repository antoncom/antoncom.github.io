# TeamTime BPM — сайт-презентация

Статический сайт для GitHub Pages.

```
/               — заглавная страница (выбор языка)
/ru/            — презентация на русском (исходник для остальных языков)
/en/ /de/ /es/ /hi/ /zh/ /ko/ — переводы, собираются скриптом из /ru/
/_i18n/         — скрипты и таблицы перевода
/assets/css/    — стили (общие для всех языков)
/assets/js/     — меню, вкладки модулей, увеличение скриншотов
/assets/img/    — логотип, иконки модулей, скриншоты
```

## Публикация

1. Создать репозиторий, например `antoncom/teamtime`.
2. Загрузить содержимое папки в ветку `main`.
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
4. Сайт появится по адресу `https://antoncom.github.io/teamtime/`.

## Переводы

Русская страница `ru/index.html` — единственный исходник. Остальные языки
собираются из неё по таблицам `_i18n/<язык>.py` (по одной строке перевода
на каждый русский фрагмент, в том же порядке).

После правки русской страницы:

```
python3 _i18n/extract.py ru/index.html   # обновить список фрагментов (segments.json)
# дописать/исправить соответствующие строки в _i18n/en.py, de.py, ...
python3 _i18n/build.py                   # пересобрать все языки
```

Сборщик сам останавливается, если для какого-то фрагмента нет перевода
или в переведённой странице осталась кириллица.

Новый язык: добавить таблицу `_i18n/<код>.py`, строку в `LANGS` в
`_i18n/build.py`, пункт в переключатель языков в `ru/index.html` и кнопку
на заглавной странице.
