# Модель А.С. Макаренко в работе директора

Сайт для GitHub Pages: https://antoncom.github.io/makarenko/

- `index.html` — заглавная страница (EN) с выбором языка
- `ru/index.html` — русская версия документа
- `ru/polozheniya/*.html` — полные тексты положений
- `assets/style.css`, `assets/nav.js` — общие стили и навигация для всех языковых версий

Новый язык: скопировать папку `ru/` в `en/` (и т.д.), перевести тексты и добавить кнопку на заглавную страницу.
