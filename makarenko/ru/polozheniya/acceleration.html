Акселерация TeamTime — характеристика применяется при найме

Полный текст положения · Оплата труда и программы

Положение описывает систему оплаты труда, применяемую в отделе разработки. Её цель: сделать рост заработной платы предсказуемым и прозрачным, связав его с опытом сотрудника, подтверждённым ежедневными рапортами.

Определение

Номинальное: от лат. acceleratio — ускорение.

В контексте методики TeamTime акселерация — это форма оплаты труда, существенным признаком которой является последовательное увеличение суммы заработной платы в зависимости от накапливаемого сотрудником опыта по специальности.

В дальнейшем для обозначения акселерации в нашем контексте будем пользоваться термином «Акселерация TeamTime».

Характеристика

Акселерация TeamTime похожа на несколько известных форм оплаты труда, но не совпадает ни с одной из них.

Чем не является Акселерация TeamTime

  • Сдельная форма оплаты труда, при которой сотруднику оплачивают количество продукции (работ, услуг), которое он произвёл.
  • Сдельно-премиальная форма оплаты труда, при которой сотруднику помимо заработной платы начисляют премии.
  • Сдельно-прогрессивная форма, при которой сдельные расценки зависят от количества произведённой продукции за тот или иной период времени.
  • Косвенно-сдельная форма оплаты, которую применяют для оплаты труда сотрудников обслуживающих и вспомогательных производств. В этом случае их заработок зависит от зарплаты сотрудников основного производства, получающих сдельно.

Существенные признаки Акселерации TeamTime

  1. Оплата труда сотрудника состоит из двух частей: оклад и сделка. Окладом является постоянная неуменьшаемая часть заработной платы. Сделка — переменная часть оплаты.
  2. Сдельная часть оплаты формируется на основе фактически выполненных работ, подтверждённых рапортами о проделанной работе с указанием фактически затраченного времени.
  3. Сумма сдельной части за месяц рассчитывается по цене часа, указанной в трудовом (или ученическом) договоре сотрудника.
  4. Цена часа сотрудника определяется главным образом на основе целевого образования, опыта по специальности, а также опыта, получаемого на данном предприятии.
  5. Образование и опыт сотрудника учитываются по единой для всех формуле (см. ниже).

Формула расчёта сдельной цены часа

hRate = Function(eduYears, eduQuality, seniorityYears, timerecordMonths, skillHours)

Назначение показателей

ПоказательНазначение
hRateцена часа по сдельной части оплаты труда (рублей);
eduYearsсколько лет образования имеет сотрудник по специальности (5 — для вуза, 3 — для техникума);
eduQualityсреднеарифметическая оценка по выпускному табелю успеваемости (от 3 до 5; красный диплом — 5);
seniorityYearsобщий стаж работы по специальности на момент трудоустройства в данное предприятие;
timerecordMonthsстаж работы на данном предприятии: исчисляется не в календарных месяцах, а на основе фактических часов из расчёта 120 часов = 1 месяц;
skillHoursопыт по навыкам, предусмотренным специальностью (от 0 до N, где N = 0 — для студента; N ≥ 720 — для Junior; N ≥ 1440 — для Middle; N = 2880 — для Senior).

Ниже приведён проект формулы. Тарифная сетка (цены часа R по уровням) и коэффициенты утверждаются руководством; значения коэффициентов даны для примера.

  • Уровень сотрудника определяется по skillHours: стажёр (0–719), Junior (720–1439), Middle (1440–2879), Senior (от 2880).
  • Внутри уровня базовая цена часа растёт равномерно, от ставки текущего уровня к ставке следующего:
Rбаз = Rуровня + (Rследующего − Rуровня) × (skillHours − Hуровня) / (Hследующего − Hуровня)

Здесь H означает порог skillHours для уровня. Для уровня Senior Rбаз = Rsenior, дальнейший рост определяет руководитель.

  • Надбавка за образование: Kобр = 1 + 0,02 × eduYears × (eduQuality − 3) / 2. Например, вуз с красным дипломом даёт Kобр = 1,10, техникум со средним баллом 4 даёт Kобр = 1,03.
  • Надбавка за стаж на данном предприятии: Kстаж = 1 + 0,01 × min(timerecordMonths / 12; 5), то есть до +5% за пять лет.
  • Стаж по специальности до прихода на завод (seniorityYears) вместе с результатами собеседования определяет начальное значение skillHours.

Итоговая цена часа:

hRate = Rбаз × Kобр × Kстаж

Подробнее о skillHours

Показатель skillHours учитывает опыт по навыкам, предусмотренным специальностью, и сильнее других влияет на цену часа. В него засчитываются только часы, подтверждённые ежедневными рапортами о выполненных задачах, поэтому рост оплаты привязан к сделанной работе.

Как это работает, удобнее показать на примерах.

Пример № 1: на предприятие пришёл студент или выпускник

Стажёр начинает с нулевого опыта (skillHours = 0) и проходит стажировку, например, 6 месяцев. При норме 120 часов в месяц это 720 часов, поэтому через полгода стажёр выходит на уровень Junior. Всё это время его цена часа растёт каждый месяц по тарифной сетке.

Пример № 2: на завод пришёл специалист уровня Junior

На собеседовании определяется входной уровень знаний и опыта по перечню навыков специальности. Допустим, кандидату присвоено начальное значение skillHours = 720. Через полгода (ещё 720 часов) он выходит на уровень Middle, а до этого его цена часа ежемесячно растёт по тарифной сетке уровня Junior.

Пример № 3: на завод пришёл специалист уровня Middle

На собеседовании определяется входной уровень знаний и опыта по перечню навыков специальности. Допустим, кандидату присвоено начальное значение skillHours = 1440. Через год (ещё 1440 часов) он выходит на уровень Senior, а до этого его цена часа ежемесячно растёт по тарифной сетке уровня Middle.
